# Attendly Mobile Pro (Flutter)

This folder contains the Flutter source code for the mobile application.

## Getting Started in Android Studio

1. **Open Android Studio**.
2. Select **Open** and choose the `attendance_pro_app` folder (the one containing this file).
3. If prompted, click **'Get Dependencies'** or run `flutter pub get` in the terminal.
4. Ensure you have a Firebase configuration file (`google-services.json` for Android, `GoogleService-Info.plist` for iOS) in the appropriate directories if you are deploying to a real project.

## Project Architecture

- `lib/main.dart`: Entry point.
- `lib/screens/`: UI screens (Dashboard, Login, etc.).
- `lib/utils/`: Support logic (GPS, etc.).
